# Support Profile

The support profile is a first-party pilot profile for support escalation
memory. It keeps Lore's five-database core unchanged while replacing the
write-time tag/entity/predicate vocabulary with support-oriented terms and
adding a few optional Notion properties for support triage.

Data policy: committed fixtures are synthetic and must not include real
customer content, PHI, regulated data, production workspace ids, or live ticket
payloads. Live-vault evals are operator-dispatched only and must use a sandbox
vault.

The profile uses default retrieval, wake-up, debt, procedure, temporal fact,
auto-mention, and cross-vault topology behavior. Procedure safety and review
gates remain core.
